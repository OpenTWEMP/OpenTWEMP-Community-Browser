# :bomb: OpenTWEMP Community Browser - Next Generation Edition

Данный документ содержит черновое описание *видения продукта (product vision)* для **версии следующего поколения** OpenTWEMP Community Browser.

---

## :pushpin: ОБНОВЛЕНИЕ СТРАТЕГИИ РАЗВЕРТЫВАНИЯ ПРИЛОЖЕНИЯ

### :star: Автономный режим работы приложения (offline-mode)

- **Клиент:** Портативное развертывание *минималистичного клиентского приложения* на устройстве пользователя.
- **Сервер:** Портативное развертывание *минималистичного серверного приложения* на устройстве пользователя.
- **Функции:** Только *базовые* возможности (отключены сетевые функции приложения).
- **Хранилище:** Выбор *локального репозитория* данных для самостоятельной установки.

### :star: Сетевой режим работы приложения на собственных мощностях (on-premise online-mode)

- **Клиент:** Развертывание *полнофункционального клиентского приложения* на устройстве пользователя.
- **Сервер:** Развертывание *полнофункционального серверного приложения* на собственных мощностях пользователя.
- **Функции:** Полный комплект возможностей *on-premise*-версии (отсутствует автоматическое обновление ПО).
- **Хранилище:** Выбор доступных вариантов *локального репозитория* данных для самостоятельной установки.

### :star: Сетевой режим работы приложения на основе облачного сервиса (cloud online-mode)

- **Клиент:** Развертывание *полнофункционального клиентского приложения* на устройстве пользователя.
- **Сервер:** Использование *официальных облачных сервисов* (отсутствует необходимость в установке серверного ПО).
- **Функции:** Полный комплект возможностей *облачной* версии (доступно полностью автоматическое обновление ПО).
- **Хранилище:** Использование *облачного репозитория* данных (отсутствует необходимость в установке репозиториев).

## :pushpin: ОБНОВЛЕНИЕ ПОДДЕРЖКИ СОВРЕМЕННЫХ ЦЕЛЕВЫХ ПЛАТФОРМ

Ожидается, что *настольное клиентское* приложение будет доступно следующих платформ:

- **Клиентское приложение для Windows**: полная поддержка для всех актуальных версий ОС (включая неподдерживаемые версии ОС, начиная с Windows 7).
- **Клиентское приложение для Linux**: полная поддержка только для ограниченного набора дистрибутивов (ведущие дистрибутивы, включая российские).
- **Клиентское приложение для macOS**: неофициальная поддержка (только портирование на macOS), тестирование исключительно усилиями сообщества.

Ожидается, что *мобильное клиентское* приложение будет доступно следующих платформ:

- **Клиентское приложение для Android**: полная поддержка для всех актуальных версий ОС (исключая морально устаревшие и неподдерживаемые версии ОС).
- **Клиентское приложение для iOS**: неофициальная поддержка (только портирование на iOS), тестирование исключительно усилиями сообщества.

Ожидается, что *серверное* приложение будет доступно следующих платформ:

- **Серверное приложение для Windows Server**: полная поддержка для всех актуальных версий ОС (включая некоторые устаревшие версии ОС, но исключая морально устаревшие версии ОС).
- **Серверное приложение для Linux**: полная поддержка только для ограниченного набора дистрибутивов (ведущие дистрибутивы, включая российские).

## :pushpin: ТЕХНОЛОГИЧЕСКИЕ НОВШЕСТВА в ОБЛАСТИ ИНЖЕНЕРНОЙ ИНФРАСТРУКТУРЫ

### :dart: Новые способы упаковки и распространения приложения

- Клиентское приложение для Windows распространяется либо как установщик MSI, либо как пакет Chocolatey/WinGet.
- Клиентское приложение для Linux распространяется разными способами в зависимости от модели развертывания.
- Клиентское приложение для macOS распространяется некоторым универсальным способом (популярные установщики пакетов ПО).
- Клиентское приложение для Android распространяется либо как установщик APK, либо через магазины приложений.
- Клиентское приложение для iOS распространяется некоторым универсальным способом (популярные установщики пакетов ПО).
- Серверное приложение для Windows Server распространяется либо как установщик MSI, либо как пакет Chocolatey/WinGet.
- Серверное приложение для Linux распространяется либо как DEB/RPM пакет, либо предустановленным в составе дистрибутива.

### :dart: Конвейер непрерывной интеграции и развертывания

- Конвейер CI/CD выполняет построение двоичных файлов приложения из исходного кода в репозитории проекта.
- Конвейер CI/CD обеспечивает запуск автоматизированных тестов проекта (smoke tests + regressions tests).
- Конвейер CI/CD осуществляет построение установочных файлов приложения и доставку артефактов в хранилище.
- Конвейер CI/CD уведомляет о результатах проделанной работы путем отправки сообщений в разные каналы связи.

### :dart: Резервные площадки для хостинга проекта

- Планируется обустроить локальную серверную инфраструктуру для хостинга проекта.
- Планируется осуществить переезд на инфраструктуру отечественных хостинг-провайдеров.
- Планируется оставить GitHub в качестве интернациональной площадки для развития проекта.

## :pushpin: ТЕХНОЛОГИЧЕСКИЕ ИЗМЕНЕНИЯ в СРЕДЕ РАЗРАБОТКИ ПРОЕКТА

- Потребуется миграция на современную версию платформы .NET (плюс Visual Studio 2026).
- Серверная часть кодовой базы будет использовать ASP.NET Core в качестве платформы.
- Клиентская часть кодовой базы основана на мульти-платформенном GUI-фреймворк (MAUI vs. Avalonia UI vs. Uno Platform).
- Клиентская часть кодовой базы будет гибридной (мульти-платформенный GUI-фреймворк + Blazor Hybrid или WebView2).
- Клиентская часть кодовой базы может быть расширена средствами языкового стека JS/TS.

## :pushpin: ОБНОВЛЕНИЕ ЛИЦЕНЗИИ на ИСПОЛЬЗОВАНИЕ ПРОГРАММНОГО ОБЕСПЕЧЕНИЯ

- Ожидается, что минималистическая портативная версия приложения продолжит распространяться под лицензией MIT.
- Для полнофункциональной версии приложения следует запретить возможность потенциального закрытия исходного кода.
- Облачный формат развертывания подразумевает переход к модели SaaS и доступ к ПО на основе линейки тарифных планов.
